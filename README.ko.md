# 뜨개 기록

[English](README.md) · [앱 열기](https://jinalee-soc.github.io/crochet/)

코바늘 작품의 호수와 메모를 기록하는 웹앱입니다. 완성작 사진을 모으고, 작품별 자랑 카드나 연간 모아보기 이미지를 만들 수 있습니다.

## 내 기록은 내 기기에 저장됩니다

GitHub Pages에서는 앱 파일을 받아 옵니다. 작품 기록과 사진은 **사용 중인 브라우저의 IndexedDB**에 저장됩니다. 이 저장소나 서버의 앱 데이터베이스에 업로드하지 않습니다.

누구나 같은 주소를 열어 자기 작품을 기록할 수 있습니다. 다른 방문자는 앱을 통해 내 기록을 볼 수 없습니다. 계정이나 별도의 로컬 서버도 필요하지 않습니다.

기기나 브라우저 사이에 자동 동기화되지는 않습니다. **백업 → 백업 파일 만들기**로 기록과 사진을 내보내세요. 다른 기기에서는 **불러오기**로 복원할 수 있습니다. 같은 작품이 있으면 백업 내용으로 덮어씁니다.

브라우저 데이터를 지우거나 기기를 바꾸기 전에 백업하세요. 브라우저 저장 공간은 삭제되거나 정리될 수 있습니다. 비공개 브라우징에서는 기록이 유지되지 않을 수 있습니다. 백업은 iCloud Drive 등 안전한 곳에 보관하세요. 카드나 백업을 공유하면 선택한 대상에게 해당 파일이 전달됩니다.

## 한국어와 영어

앱 상단의 **국문 ↔ ENG** 버튼을 누르면 한국어와 영어가 전환됩니다. 처음 열 때는 브라우저 언어가 한국어이면 한국어로, 그 외에는 영어로 표시합니다. 브라우저 저장 공간을 사용할 수 있으면 선택한 언어를 기억합니다.

화면, 안내 메시지, 날짜, 공유 카드의 항목 이름이 선택한 언어로 바뀝니다. 직접 입력한 작품 이름과 메모는 그대로 남습니다. 언어를 바꿔도 기록이나 사진을 이동·번역·삭제하지 않습니다.

## 앱처럼 사용하기

아이폰 Safari에서 사이트를 연 뒤 **공유 → 홈 화면에 추가**를 선택하세요. 앱 파일이 처음 캐시된 후에는 오프라인에서도 사용할 수 있습니다. 업데이트를 받으려면 온라인에서 열어 주세요.

원하는 언어를 선택한 뒤 홈 화면에 추가하세요. 이미 추가한 아이콘 이름은 앱 안에서 언어를 바꿔도 처음 이름으로 남을 수 있습니다.

## 개발

별도 빌드나 백엔드가 없는 정적 웹앱입니다.

```sh
python3 -m http.server 8000
node tests/i18n.test.cjs
```

`http://localhost:8000`에서 확인하세요. 번역은 `i18n.js`에 있습니다. 변경 사항을 배포할 때는 `sw.js`의 캐시 버전을 올리세요. 오프라인에서 필요한 새 파일은 `SHELL` 목록에도 추가하세요. 두 언어의 매니페스트는 같은 앱 식별자와 저장 공간을 사용합니다.
